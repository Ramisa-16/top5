## 🎯 How It Works — 3 Steps

```
1. Choose a Category
   (food, movies, places, products, etc.)
        │
        ▼
2. Set Your Filters
   (budget, location, style preferences)
        │
        ▼
3. AI Returns Top 5
   (ranked, personalised, no clutter)
```

---

## ✨ Features

- **Top 5 Only** — no information overload, just the best matches
- **Category System** — works across any domain
- **Smart Filters** — budget, location, preferences
- **"Ideas to Try"** — AI suggestions based on weather and time of day
  - Rainy evening → "Top 5 cozy cafés nearby"
  - Sunny weekend → "Top 5 outdoor spots to explore"
- **Learns Taste** — AI adapts to user preferences over time
- **Minimal UX** — fast, clean, intuitive interface
